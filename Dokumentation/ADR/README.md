# Architecture Decision Records

Für die aktuelle Main-Codebasis wurde kein belastbarer Bestand formaler ADRs gefunden. Architekturhinweise aus `docs/ARCHITECTURE.md`, Mobile `OPEN_DECISIONS.md` und den neuen Mobility-Dokumenten sind Design-/Statusquellen, keine automatisch beschlossenen ADRs.

Neue ADRs sollten Datum, Status (proposed/accepted/superseded), Kontext, Entscheidung, Alternativen und Code-/Testbelege enthalten. Offene Mobile-Fragen bleiben offen, bis sie ausdrücklich entschieden sind.
